# Exploratory PKIS2 threshold-boundary audit

This audit was specified after the main results and after observing that the
PKIS2 workbook contains values exactly equal to 80 and 90. It reports every
cell in a complete, mechanically defined grid: parent-collapsed and
construct-resolved targets; thresholds 80 and 90; standard and chemotype
reference exclusions; and inclusive (`>=`) labels. It uses the unchanged
K=9 bounded policy, marginal comparator, budget 20, and inference procedure.

The purpose is narrow: determine whether the paper's strict-versus-inclusive
threshold convention changes the qualitative PKIS2 conclusions. This is an
exploratory robustness check and cannot validate either threshold as a
biologically privileged cutoff.
